Reproduce in a scratch directory: copy Program.cs.txt and Probe.csproj.txt as Program.cs and Probe.csproj, then run dotnet run --project <scratch>/Probe.csproj -c Release -- <repository-root>. Requires the baseline Release build. Probe mutates a COPY of the DLL in /tmp, never the shipped subject. It invokes the three existing private scanner methods and demonstrates that a valid PE without CLR metadata produces an empty violations collection. This is a finding probe, not a replacement production guard.
